根目录作为 Jekyll 站点的装配层：_config.yml 声明 theme: minima、permalink 格式（/:year/:month/:day/:title.html）、markdown: kramdown 与 highlighter: rouge，并启用 jekyll-sitemap/jekyll-seo-tag/jekyll-feed 三个官方插件；Gemfile 在 Ruby ≥ 4.0 时绕过 github-pages gem 直接锁定 jekyll ~3.9 + minima ~2.5 + liquid >= 4.0.4。线上构建由 .github/workflows/pages.yml 定义的 GitHub Actions 流水线承担（Ruby 4.0 + JEKYLL_ENV=production），与本地同走显式依赖分支，_plugins/ 自定义插件全部生效。运行时各子模块按约定被 Jekyll 发现——posts/ 提供 Markdown 源，theme_assets/ 覆盖主题布局与片段，static_assets/ 注入 CSS/JS/图片，site_pages/ 生成 RSS 与搜索索引等静态页面，最终经 Actions 产物上传发布为 https://lzc6244.github.io/。
